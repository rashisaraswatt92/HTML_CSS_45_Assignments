HTML Debugging Checklist

Use this valid example to compare with a buggy file:

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>Correct Page</title>
</head>
<body>
  <h1>Hello</h1>
  <p>Paragraph text.</p>
</body>
</html>

Check that tags are closed, nesting is correct, and attributes are quoted.
