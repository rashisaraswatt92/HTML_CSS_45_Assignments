Terminal Navigation Practice

  1. pwd — show current folder
  2. ls — list files (macOS/Linux/Git Bash)
  3. cd folder-name — enter a folder
  4. cd .. — go up one folder
  5. mkdir practice — create a folder
  6. touch notes.txt — create a file in Git Bash/macOS/Linux

Windows PowerShell alternatives include Get-Location, Get-ChildItem, and New-Item notes.txt.
