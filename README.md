# HTML & CSS Practical Assignments — Starter Project

This project contains 45 HTML starter pages based on the supplied two-page assignment PDF, a shared CSS file, task notes, a landing index, and Windows Git helper instructions.

## Open and preview
1. Extract the ZIP.
2. Open this folder in Visual Studio Code using **File → Open Folder**.
3. Open `index.html` and use Live Server, or open the file directly in a browser.
4. Click any assignment link. Read that folder's `TASK.txt` and compare the page with the original assignment PDF.
5. Replace placeholder details, test the page, and save your changes.

## Git / GitHub
- Intended GitHub account supplied by the requester: `rashisaraswatt92` (Rashi Saraswat).
- Create a repository named `html-css-practical-assignments` while signed in to an account you are authorised to use.
- Read `TERMINAL_GUIDE.txt` before pushing.
- On Windows, `START_REPOSITORY_WINDOWS.bat` creates the local repository and makes one initial commit. It does not push anything online.
- After making real improvements, make additional meaningful commits and push them. Never fabricate commit history.

## Please review before submission
This is a prepared starter project, not proof that all assignment criteria have already been satisfied. The PDF includes tasks that require real evidence or work outside a sample webpage (for example, setup screenshots, terminal practice, Git history, and debugging a supplied file). The supplied PDF does not include a separate buggy HTML file or a reference landing-page screenshot. Complete those parts using your class materials and your own evidence.

The pages use sample/placeholder content. Personalise the content and inspect all pages, links, forms, layouts, image alt text, and mobile responsiveness before submitting. Some example forms are demonstrations only and do not store or send data.
