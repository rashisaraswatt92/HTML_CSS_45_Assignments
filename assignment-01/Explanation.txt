When we enter a URL into a web browser,the browser first identifies the website's address and checks whether the page is already available in its cache. It then uses DNS to finds the server's IP address.The broser establishes a connection with the server and sends an HTTP or HTTPS request. The server processes the request and sends a response containing HTML,CSS,Javascript,images or other resources. Finally, the browser interprets these resources and displays the webpage on the screen.
